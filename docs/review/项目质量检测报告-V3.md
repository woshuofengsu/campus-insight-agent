## 三、逐维度检测（重点：V2 问题闭环情况与剩余硬伤）

### A. 多 Agent 架构（8.5，+0.5）
- ✅ **A2 真协商落地**：`orchestrator._drain_negotiations` 链式多轮——一次用户输入内天气→健康→通知三 Agent 消息往返（健康确认→天气升级→通知草稿），跳过 receptionist 防轮次误累加；循环防护（单目标 2 轮 + 遍历 5 次）保留。
- ✅ A1 角色建模结构化（9 声明式角色/工具白名单/停机点）+ A3 编排（执行链/超时重试/锁冲突）+ A5 上下文（会话落库 v31 + 草稿落库 v35 + 转人工包快照）。
- ❌ A4 无热插拔/同角色多实例；黑板内存不跨 worker 共享（state/draft 均已落库缓解）。
- ❌ 真协商为规则驱动剧本，非 LLM 自主协商（接 key 后由 prompt 承担，评测集已留接口）。

### B. 业务闭环（9.5，+0.5）
- ✅ **红黑榜 + 满意度下钻**（P2-B4-01）：db_board.py 红榜（满意工单/高效网格员/完成提案）vs 黑榜（不满意/SLA 超时/低效网格员），`GET /agent/board` + `/agent/satisfaction-drilldown` 下钻到单工单。
- ✅ **AI 自转率量化**（P3-B5-01）：`get_self_resolution_stats` 按 agent_logs+handoffs 聚合，真实库实测 **62%**（AI 58 / 转人工 26）；大屏「AI 自转率」卡。
- ✅ 报修（重复合并/跨部门仲裁/超时升级/满意度闭环）+ 舆情（分级/一键转工单/简报）。
- ❌ 舆情外部源（12345 API/媒体抓取）仅 auto_ingest 占位，未接真实源。

### C. Agent 能力（8.5，+1.0）
- ✅ **NLU 增强**（P1-C1-01）：方言归一化（北京/上海词表）+ 指代消解（recent_entity）+ 否定纠偏（不是A是B），receptionist/orchestrator/service 三处同口径；test_nlu.py 10 项。
- ✅ **LLM 评测集**（P1-D3-01）：20 条 golden（政策/报修/健康/注入/转人工/方言/否定）+ scripts/llm_eval.py 五维跑分 **20/20 满分** + CI 接入；评测暴露并修复健康紧急症状触发、注入变体词表 2 个真 bug。
- ✅ 幻觉防线（Verifier 引用强制/健康不诊断/网格不代替审批）+ 注入防护（6 类输入过滤/输出检测/提示加固）。
- ❌ 仍规则级（无向量语义）；接 LLM 后需补分级模型路由。

### D. 数据与智能（7.5，+0.5）

- ❌ 无向量库/知识图谱/趋势预测；bad case 人工标注回流流程未跑通（需接 LLM 后）。

### E. 体验（8.5，+0.2）
