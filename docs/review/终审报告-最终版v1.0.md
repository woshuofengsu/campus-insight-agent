## 二、核心优势（最终站得住的 5 个）

1. **多智能体是"真协作"而非套壳**：9 声明式角色 + 黑板（带锁/版本/历史封顶 500）+ 五类消息协议 + Verifier/Arbiter 双层防线且决策落 agent_logs，天气⇄健康、报修→通知升级等协商链路可在 demo_acceptance 与 agent_logs 里当场查到。
2. **数据安全真正闭环**：AES-256-GCM，**全库 8 张含手机号表明文=0**（v46 把第七轮抓到的提案 181 条明文、两张草稿表、user_profile 残留一次性补齐，且"加密成功才清明文"可重试）；JWT secure-by-default、鉴权中间件前置 401、安全头齐全、上传白名单+5MB 双校验、导出脱敏、注销级联。
3. **"质量可复算"的工程自觉是最大亮点**：9 类客观 UI 审计（连"渲染后残缺文本 °~°/undefined"都扫）、42 条口语金标 hit@1 100% vs 词法 85.7%、LLM 20 题满分且单次成本 ¥0.0053 可记账、对外数字有门禁核对。答辩被问"怎么保证"，每条都能当场跑。
4. **三端适老是"降噪"不是"放大"**：字号 max(rem,px) 保底≥20px、热区≥72px、只保留 SOS 呼吸动效、全站 prefers-reduced-motion、暗/亮双主题对比度按 WCAG AA 实测调到达标，且用脚本卡阈值。
5. **诚实**：最终版交付说明单列"已知边界/演示数据非真实成效/LLM 默认按需/多租户预留/单机形态"，不夸大；每轮复审报告连同"未修复项与理由"都留档。这种诚实本身是答辩加分项。
