## 二、好的方面（强证据）

1. **多智能体是真协作，不是伪多智能体**
   - 9 个声明式角色（`agent/roles/__init__.py`）+ 黑板消息队列（`agent/blackboard.py`）+ **真实 Agent↔Agent 消息往返**（天气→健康→通知 链式协商，`orchestrator._drain_negotiations`）。
   - 双层防线：`verifier`（幻觉/敏感词/手机号/处方诊断句式拦截）+ `arbiter`（合规→安全→专业→人工，决策落 `agent_logs` 留痕）。执行链（execution_chain）可对评委展示。

2. **安全底子扎实（这轮评审重点）**
   - 手机号**真 AES-256-GCM**：主库 376 条密文全部 `g1$` 前缀、可解、可轮换（`scripts/reencrypt_phones.py`，幂等+先备份）。
   - **secure-by-default**：未配 `WEB_JWT_SECRET` 且未显式 `DEMO_MODE=true` 拒启。
   - 越权/篡改/alg:none/防爆破、上传**路径穿越+扩展名白名单**、PIPL 注销**级联匿名化**（user_profile + emergency_contacts + health_consults + community_issues + proposals 的 PII 与密文全清）、授权 **fail-closed**（notices）、SQLite `busy_timeout`。

3. **"真 AI 证据链"完整**
   - 政策真 RAG（结构化 `cited_index` 引用校验，材料不全不生成）；接待员 LLM 白名单意图兜底；LLM 统一客户端（熔断+超时+记账）；`llm_usage` 成本留痕——**这些都有"默认关"开关，规则保底，可一键切换**。
   - 仲裁**能改变结果**（健康↔天气分歧 → 专业优先/转人工，`need_human`），并有真实链路可演示。

4. **测试与可验证性**
   - 512 项全绿；金标评测（`agent/eval/golden/*` 离线、进 CI）；业务混合压测（`benchmark_business.py` p50/p95/p99）；`scripts/check_claims.py` 数字自检防止材料与代码"两张皮"；CI 已接 ruff + pytest + 前端构建。

5. **人情味是真能力（近一轮）**
   - `agent/tone.py` 关怀内核 + `_finish` 统一前置情绪安抚/场景共情（会话级去重）；用药打卡闭环（v42，`我吃了`/连续天数，`snooze` 不占名额）；办结回访+久未活跃（`db_care_proactive.py`）。全部规则驱动、可测、零 LLM。

## 三、坏的方面（诚实 + 风险分级）

### 高影响（待处理）
- **1. 规模化落地欠账（WS11 级）**：会话缓存（`_agent_orchs`）、WebSocket 连接池、登录限流均为**单进程内存态**；SQLite 单库，多副本/多租户未闭环。答辩能演，但"真实街镇多社区落地"证据不足——材料里已诚实声明"字段预留/未完成"，**严禁呈现为已完成**。
- **2. 可维护性结构偏重**：`data/db_policy|proposal|elderly_care|health_content|weather|notice` 均 800–1240 行，SQL 与业务规则耦合。赛期"只评估不重构"是对的，但长期需按 read/write 拆分（已列入 WS11）。

### 中影响（答辩/演示风险）
- **3. 前端交互未做真机冒烟**：M1–M4 的按钮/播报/语速只到"构建通过+逻辑审阅"，**pytest 覆盖不到 Vue 运行时**。答辩前务必在演示机手动点一遍"李阿姨"故事线。
- **4. 情感拼句是启发式**：`_finish` 前置"安抚+共情+原文"可能偏啰嗦；情绪词跨轮反复出现会再安抚（去重为同会话、不限次数）。
- **5. `DEMO_AUTO_WORKER` 语义边界**：演示库由机器人推进工单，**不代表真实治理成效**；对外话术必须"规则为骨、LLM 为脑、关键节点人确认"，且 `.env.demo` 需真 key + `cp` 到 `.env` 才生效。

### 低影响（赛后技术债，已认定）
- **6. `ui/` 旧链（1.3 万行 Streamlit）仍在**；`app.py`、`api.py`（扣子）为入口，主链路虽已脱离 `ui/`，但 legacy 未归档。
- **7. `datetime.utcnow()` 告警 ~103 条**（日期字符串格式，风险>收益未动）。
- **8. 异常文本回传**：仍有 8 处 `f"...：{e}"` 把内部异常透给客户端（upload.py 已改，其余待专项）。
- **9. `login_guard` 可轮换 IP 绕过**（内存版单进程够用；换 Redis 实现时一并处理）。
- **10. 长文本输入/limit 上限未全量约束**：LLM 入口已截断 + chat 限流，但字段级 `max_length` 与列表 `limit` 未铺开。

## 四、数据与合规（评分高）

- 加密：AES-256-GCM（非自研流密码），密文版本前缀、旧密文兼容、可重加密轮换。
- PIPL：加密存储、展示脱敏、日志去号、导出（脱敏）、注销（级联匿名化）、权限 fail-closed。
- JWT：HS256 + secure-by-default + 过期 + 防爆破。
- **明确缺**：等保定级/密评、PIPL 同意书与共享台账、KMS、真实数据源授权——均已列入合规路线一页，**为"规划项/差距"，非已完成**。

## 五、答辩/演示 P0 清单（照做）

1. **准备 `.env.demo`**（模板 `.env.demo.example`）→ 填真 `DEEPSEEK_API_KEY` → `cp .env.demo .env` → 重启；否则 LLM 开关虽为 1 但无 key 会回落规则。
2. **演示机冒烟**：三端主路径 + "李阿姨"故事线（问候/关怀/情绪安抚/用药打卡/SOS 先安抚/办结回访）。
3. **断网兜底**：切 LLM 全关 `.env`，规则链路照样演。
4. **口径诚实**：多智能体=声明式+黑板+校验/仲裁（非"9 全自主 AI"）；语音=普通话；SOS=通知+手动拨120；数据=种子+机器人演示不代表真实成效。
5. **现场可跑三件**：`pytest -q`（512 绿）、一次开 LLM 的联动+费用、转人工一跳。
