# 演示保障清单（WS8.3，答辩前必查）

> 目的：让"现场演示"在受控环境下不翻车；同时对外话术诚实（不夸大能力）。

## 一、演示机准备

- [ ] 专用演示机（一台 Windows / macOS 机器提前固定，不临时换机）。
- [ ] 浏览器用 **Chrome 或 Edge**（Web Speech / TTS 支持最好），装中文语音包（`zh-CN`）。
- [ ] 自备手机热点或提前连好会场 WiFi，**不依赖现场网**；断网也有本地兜底脚本可演规则全流程。
- [ ] 语音需 HTTPS（`SpeechRecognition` 在非安全上下文被禁，`useSpeech` 已对 `https-required` 给出提示）。本地演示请用 `localhost` 或自签证书，并提前验证"按住说话→转写确认"可用。

## 二、服务与配置（两套姿态）

> **演示前 10 分钟（照做即可）**
> 1. 填 key：用文本编辑器打开 `.env.demo`，把 `DEEPSEEK_API_KEY=` 那行换成 `平台申请到的真实 key`（**不填 key，LLM 开关全为 0，生成链路会触发不了** —— 这是最容易翻车的一点）。
> 2. 切演示姿态（要演 AI 生成 / 自主协商）：`Copy-Item .env.demo .env`（或 `cp .env.demo .env`），然后重启服务。
> 3. 切兜底姿态（断网 / 只演规则流程）：用一份 `LLM_ORCHESTRATION=0、POLICY_LLM_RAG=0、RECEPTION_LLM_FALLBACK=0` 的 `.env` 覆盖，重启服务即可。
> 4. 启动：`python -m uvicorn api_web:app --host 0.0.0.0 --port 8000`；前端已构建（`web/dist` 存在）。
> 5. 快速自检：在居民端问一条政策（如"低保怎么申请"），若返回带**"参考：…"且说明 AI 依据知识库生成** = LLM 已通；若直接转人工或无引用 = 检查 `.env` 开关/Q key 是否复制对。
> 6. 三端各走一遍主路径：`/resident`、`/grid`、`/elderly`。

- [ ] **演示姿态 `.env.demo`**：`DEMO_MODE=true`、`DEEPSEEK_API_KEY` 已配真 key、LLM 开（`LLM_ORCHESTRATION=1`、`POLICY_LLM_RAG=1`、`RECEPTION_LLM_FALLBACK=1`）、`DEMO_AUTO_WORKER=true`。
- [ ] **兜底（断网）姿态**：备份一份 `.env`（LLM 全关、`DEMO_MODE=true`），演示机断网时一键切回规则全流程——**规则链路不依赖 LLM**，照样能演"接诉→分派→解决→通知"闭环。
- [ ] 启动命令：`python -m uvicorn api_web:app --host 0.0.0.0 --port 8000`，前端已构建（`web/dist` 存在）。
- [ ] 三端入口各跑一遍主路径：`/resident`、`/grid`、`/elderly`。

## 三、两条必演链路（先彩排 2 遍再正式）

1. **多智能体联动（LLM 开关开）**：天气红色预警 → 健康顾问 → **仲裁改判**（健康→天气→[仲裁·专业优先] 改判避免外出，`need_human` 升级）→ 通知管理员生成草稿。同屏展示执行链（execution_chain）与 `llm_usage` 费用。
2. **攻防演示（规则链路，断网也能演）**：Prompt 注入被拦、健康"处方句式"被拦、伪造 token / 越权被拒（`/demo` 生产 403）、政策无来源转人工。
3. **转人工一跳**：居民端诉求 → 人工处理包（handoff）→ 网格员端打开即处理。

## 四、对外话术要诚实（不夸大，提前背熟）

- **多智能体**：说"9 个声明式角色 + 黑板消息队列真协商 + 校验/仲裁留痕"，**不要**说"9 个全自主 AI"。
- **语音**：H5 只支持普通话（`zh-CN`），方言识别是规划项（NLU 已留方言归一）；浏览器不支持时降级为大字文字输入。
- **紧急求助**：H5 **无法真实连续拨号**，是"后台已发求助提醒 + 记录日志 + 可手动拨打 120"。
- **数据**：演示库为种子 + `DEMO_AUTO_WORKER` 机器人推进的示例数据，**不代表真实治理成效**；对外按"规则为骨、LLM 为脑、关键节点人确认"表述。

## 五、验收点

- [ ] 在一台**不支持语音**的浏览器（如无麦克风权限/旧内核）上，老年端有**明确降级提示**并聚焦文字输入框，而不是无响应。
- [ ] SOS 文案与实际行为一致（已通知联系人 + 手动拨 120），不承诺"自动依次呼叫"。
- [ ] 断网时切 `.env`（LLM 全关）能完整演规则主流程，无 500。
