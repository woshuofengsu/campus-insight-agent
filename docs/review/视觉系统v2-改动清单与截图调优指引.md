## 三、安全开关（觉得动效多余时，优先用这个而不是删代码）

- **系统级**：打开 Windows「设置 → 辅助功能 → 视觉效果 → 动画效果」关闭，或浏览器/系统开启
  `prefers-reduced-motion: reduce` → **全部循环动效自动停止**（`style.css` 末尾统一处理，已实测）。
- **想整体更保守**：把 `.wave`/`.breathe`/`.title-sheen` 三个类从组件上摘掉即可，其余样式不受影响。
- **老年端**：只保留了「SOS 呼吸 + 淡入」两处，这是有意的——既是适老可达性论点，也避免被质疑炫技。
  如果评委席觉得呼吸太抢眼，我可以改成「仅首次进入时呼吸 3 次」而不是常驻循环。

## 四、本轮同时修掉的两个真 bug（与视觉无关，但评审会看见）

1. **网格员工作台四个统计卡恒为 0**（`grid/Dashboard.vue`）：`cards` 是普通数组，在 `setup` 期就求值，
   数据 `onMounted` 才回来 → 数组里锁死的永远是初始 `0`。已改 `computed`。
2. **`scripts/demo_preflight.py` 在中文 Windows 控制台直接崩**：GBK 控制台编码不了 `✅` →
   `UnicodeEncodeError`、退出码 1。**答辩前必跑此脚本**，崩在这里是最糟的失败模式。已加 UTF-8 强制输出，
   并补了回归测试 `test_utf8_stdout_guard_never_raises`。
