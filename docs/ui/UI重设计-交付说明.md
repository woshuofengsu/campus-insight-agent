## 三、老年端（任务书 §四）

**首页三层**（原来是卡片平铺，没有主次）
1. 问候 + 「今天想办理什么？说一声、点一下都行。」+ **三个主要动作**：反映问题 / 看看进度 / 问一问
2. 今天要留意（关怀 + 用药合并）· **最近办理**（现在到哪一步 + 下一步谁做 + 完整进度入口）· 未读通知 · 最近求助/联系
3. 天气（可听）· 更多服务 / 联系家人 / 健康服务 · 音量 · 「听一遍这一页怎么用」
- **紧急求助与拨打 120 独立、深红、够大**，整页只有这两块是红的
- 三个主要动作的第三格由「更多服务」改成「问一问」：因为「更多服务」**同时是顶部导航 6 个入口之一**（重复），
  改完反而少了一处重复；顶部导航的「更多服务」按钮与 6 个入口**原样保留**

**确认卡**（任务书 §四.3 的六件事，按顺序）
① 您反映的问题 → ② 在哪儿 → ③ 现在到哪一步 → ④ 下一步由谁处理 → ⑤ 事项编号 → ⑥ 接下来会怎样；
**技术细节全部折进「查看详细记录（分类、判断依据、提交编号）」**（原生 `<details>`，不写 JS），
卡片正文里**一个技术词都没有**（不写 Agent/Verifier 这类字眼）。

**进度页**：标题从内部自增 id 改成**事项编号**；空状态补"去反映问题"大按钮；五步进度与"现在/下一步/谁做/多久/超时"全保留。

**更多服务**：分三组（办理服务 / 健康与提醒 / 联系与帮助），**不新增一级导航**。

## 四、居民端（任务书 §五）

- 首页第一层改成「**我要办事**（报修/反映问题）· **查看我的进度** · **问社区问题**」；
  其它 6 个入口降到"其它服务"次级区域；小助手表头去渐变、文案改成「有事直接说（社区小助手）」
- 政策问答：**默认只给结论**；「适用地区」标签保留；依据（哪份政策/生效日期/匹配方式）收进
  「**查看依据**」折叠面板；**没有依据时明确说"暂时无法确认"** 并给「提交人工咨询」；
  原来那句「AI 依据知识库生成 · 已校验引用」改成「依据社区知识库整理，引用已核对」（去内部术语）

## 五、网格员端（任务书 §六）

- 工作台第一层固定四格：**待研判 / 待处理 / 待回访 / 已完成**，每格下面写口径
  （例如"待研判 = 等我审核判断"），并从同一份工单列表算出真实数量（不新增接口、不编数字）
- 待办列表标题改「先处理这些」，说明排序规则（超时 → 紧急 → 一般），超时/紧急有明确标记
- 工单展开区改**左信息 / 右操作**两栏；操作区在宽屏**吸顶**（长单不用来回滚找按钮）；
  窄屏（≤900px）自动落成一栏，手机上不至于两栏都看不清
- **分析详情**折叠（字段来源/代报/traceId 留痕），需要追溯时再展开
- 治理情景模拟器**公式与参数来源一直显示**（未配置人均可用工时 → 明说"无法折算人手"，不给默认数字）
- 治理大屏（`/screen`）去渐变背景/呼吸光斑/标题流光/数字滚动/悬停辉光，只留清楚的数

## 八、已知问题（如实登记）

1. **不是每个页面都有独立的 loading 骨架**：部分页面在数据回来前是"空白区域"而不是骨架屏
   （不显示错误状态，只是没有占位）。已做到"空数据/错误状态都有下一步动作"，但
   **loading 骨架仍是欠账**；补齐清单：`resident/Home`、`resident/Health`、`resident/Weather`、
   `grid/Weather`、`elderly/Contacts`、`elderly/Health`、`elderly/Home`。
2. **真机与真实老人观察未开展**（只能由人做）。
3. **大屏 `/screen` 只做了"去特效"**，未重排信息层级（8 卡布局未动）。
4. 门禁是"数值型"的（渐变/发光/动画/字号/对比度/溢出），**审美判断仍需人看截图**
   （AI 侧无法读图：本轮验收靠客观审计 + 人看 `.shots/pilot-ui-baseline` 与 `.shots/pilot-ui-after`）。
5. 320px 下老年端三列快捷动作会落成两列（原有设计，`@media (max-width:359px)`），未改。

## 九、`pilot-ui-v1` 版本说明

- **含义**：本版是"界面冻结版"。**真实老人观察必须在本版上进行，观察期间不再改界面**。
- **与上一版的关系**：`pilot-v1` 是"服务台能力完成"的冻结版（观察尚未开始）；
  `pilot-ui-v1` 是"界面重设计完成"的冻结版，**取代它作为观察的界面基线**。
- **冻结怎么保证**：`scripts/freeze_check.py` 对着冻结标签逐字比对老年端界面
  （页面/布局/语音与 SOS/图标/样式表），有改动直接红；观察期每次跑一遍。
- **回退**：代码回退到标签即可；数据库无迁移变化（schema 仍 v54），无需数据回滚。
