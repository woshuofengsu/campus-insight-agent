## 四、三条红线（避免现场穿帮）

1. 名字念 **步承泽**（不是"顾承泽"）。
2. **批量派单 / 批量关闭、红黑榜 · 满意度下钻都已做、有测试**——第 11 页可大方讲，但按稿一句话带过，别现场即兴点开翻。
3. 通知是 **普通 / 紧急 / 定时** 三类；**主动交代**：工程原型、没在真实街道试点、没有运营数据、演示数据全为程序生成、手机号加密脱敏。

## 五、三种意外，各一句话

- **PPT/投影打不开** → "我先用 PDF 放一遍，内容一样。"
- **翻错页 / 翻页笔失灵** → "我往回一页。"（用键盘方向键；错页别解释超过 3 秒）
- **紧张忘词** → "我停一下，看一眼笔记。"（每页只说清一件事，少说比错说好）
