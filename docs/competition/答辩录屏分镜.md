# 答辩录屏分镜与备用素材（第七轮复审建议 #5）

> 为什么要有这个：现场设备可能带不动动效（低端投影笔记本、系统开了「减少动态」、浏览器限制），
> 录屏是**兜底素材**。全部用真实浏览器录制，不剪辑、不合成、不加速——评审看到的就是产品真实行为。
>
> 一键重录：`python scripts/demo_record.py`（需服务已在 :8000 运行；只读页面，不写业务数据）
> 产物目录：`.recordings/`（已 gitignore，不占仓库体积）

## 一、已产出的素材（实测数据）

| 文件 | 内容 | 分辨率 | 时长 | 大小 | 用途 |
|---|---|---|---|---|---|

| `03-grid.webm` | 网格员工作台：**真实统计数字滚动** + 红黑榜 + 满意度下钻抽屉 | 1440×900 | 13.5s | 1.3MB | 讲治理侧实用性 |
| `04-elderly.webm` | 老年端：大字首页 + 暖色面板 + **SOS 长按 3 秒 → 确认框倒计时 → 取消** | 390×844 | 14.1s | 1.1MB | 讲适老与安全兜底 |

每个场景另存 2~3 张**关键帧 PNG**（如 `04-elderly-03.png` 就是 SOS 确认框那一帧），
可直接拖进 PPT，不用从视频里截。

**录制脚本刻意不做的事**：不发真实 SOS（长按后点「取消」，零业务写入）、不发报修、不改任何数据。
（`07-region` 是唯一的例外：它真的提了两次政策问题——但那只是检索问答，**不写业务数据**，只写提问留痕。）

## 二、播放与转码

- **播放**：`.webm`（VP8）用 Chrome / Edge / VLC / Windows 11「媒体播放器」都能直接播。
  答辩现场**最稳的播法是浏览器全屏播放**（不依赖额外播放器）。
- **转 mp4**（如果 PPT 必须嵌 mp4）：本机 Playwright 自带的 ffmpeg 是精简版（只有 VP8），
  需要装一个完整 ffmpeg 后执行：

  ```powershell
  winget install Gyan.FFmpeg          # 或从 ffmpeg.org 下载解压后加入 PATH
  cd .recordings
  Get-ChildItem *.webm | ForEach-Object {
    ffmpeg -i $_.Name -c:v libx264 -pix_fmt yuv420p -crf 20 -movflags +faststart ($_.BaseName + ".mp4")
  }
  ```

  竖屏素材（居民端/老年端 390×844）如果 PPT 是横版，建议**并排两张**或只截关键帧，
  不要把竖屏视频硬塞进 16:9。

## 三、答辩现场用法（与讲述脚本对应）

| 时间点 | 讲什么 | 用什么素材 |
|---|---|---|
| 开场 30s | 三端一句话定位 + 治理大屏 | 现场开 `/screen`；带不动就用 `05-screen.webm` |
| 中段 1min | 居民报修 → 多智能体协作 → 双层防线 | 现场走一遍；兜底 `06-agent-chat.webm` |
| **属地环节 1min** | **同一句话两个社区 → 属地只改"选谁"、不采定位** | 现场切两个账号；兜底 **`07-region.webm`** |
| 适老环节 1min | 「适老不是放大字号，而是降噪」 | 现场开 `/elderly/home`；兜底 `04-elderly.webm` |
| 治理环节 1min | 工作台真实数字 + 满意度下钻 | 现场点开；兜底 `03-grid.webm` |

**现场优先级**：现场演示 > 录屏。录屏只在设备不给力时用——所以录屏里出现的数字必须与现场一致，
这也是为什么登录页数字有自动核对（见 `docs/review/UI-v2评审-处理回执.md`）的原因。

## 四、重录与维护

```powershell
python scripts/demo_record.py                       # 全部重录（约 3 分钟）
python scripts/demo_record.py --only 07-region      # 只重录某个场景（属地对比）
python scripts/demo_record.py --out D:\答辩素材      # 换输出目录
```

> `07-region` 依赖两个演示账号都在库里：`demo_resident`（海淀小区，免密）与
> `demo_resident_cy / demo123`（朝阳试点社区）。缺第二个账号时会打印"属地场景降级"并跳过该段——
> 那是种子数据被改动过的信号（`data/seed.py::_seed_users`），不是录制脚本的问题。

- 脚本会**自动清理**上一轮遗留的 `page@xxxx.webm`（Playwright 的原始录像）与 0 字节残片，
  并生成 `index.md` 清单（含实测时长/大小/静帧数）。
- 录屏里若出现 `undefined`/`°~°` 一类残缺文本，说明**数据层字段对不上**——
  `scripts/ui_audit.py` 第 9 类检查就是为这类问题准备的（见 `docs/spec/dev-log.md` 第三十六、三十七节）。
