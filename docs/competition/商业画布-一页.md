# 商业画布一页（WS10.1）—— 社区先知 CommunityInsight

| 画布模块 | 内容 |
|----------|------|
| **客户细分** | 街道办 / 社区居委会 / 物业公司（基层治理"最后一公里"）；核心场景：接诉即办、独居老人关怀、居民触达 |
| **价值主张** | ① 把工单从"提交→流转→反馈"压缩到居民侧一句话完成；② 适老化（大字/语音/紧急求助）让老人也能用；③ 网格员减负：AI 预处理+分类+转交，人只做裁决；④ 全程留痕可审计、指标可量化 |
| **渠道** | 社区网格员推广 + 居委会试点 + 政务/物业 SaaS 渠道；产品形态 web（三端）+ 微信小程序 |
| **客户关系** | 试点社区长期运营（部署+培训+数据看板）；按街道订阅 |
| **收入来源** | 年订阅 **3–15 万/街道**（按规模）+ 一次实施培训费 + AI/座席增值包。LLM 成本近 0（规则优先降本，见 llm_usage 实测单价） |
| **核心资源** | 多智能体编排（9 角色+黑板+校验/仲裁）、`llm_usage` 成本记账、评测集与金标、数据加密与审计留痕 |
| **关键活动** | 试点部署、数据导入（网格员代录/居民自助/物业 Excel）、运营陪跑、看板解读 |
| **伙伴** | 社区居委会（数据/推广）、物业（工单闭环）、大模型厂商（DeepSeek） |
| **成本结构** | 主要是**实施与运营人力**（部署/培训/陪跑）；计算与 LLM 成本极低（规则优先） |
| **差异化** | 不做"城市大脑"级的大屏与全局治理；专注**居民侧触达 + 人机协同**，做城市大脑不愿做的细活；规则为骨、LLM 为脑、关键节点人确认 |
| **里程碑** | 1 个试点社区 → 3 个社区 → 1 个街道（年订阅）；先跑通真数据闭环，再扩规模 |

> 建议口径：定位"接诉即办的居民侧智能入口 + 网格员减负助手"，而非替代政务平台。
