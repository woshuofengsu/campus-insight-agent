# 12-数据安全与合规设计（项目适配版 v3.0）

> 依据《数据安全与合规设计（最终完善版 v3.0）》落地，并按本项目（FastAPI+Vue3，零第三方依赖哲学）
> 适配：加密用 Python stdlib 等价实现（生产可无缝切 AES-256-GCM）、演示账号策略、增量落地不破坏存量。

## 一、数据分类分级

| 类别 | 字段 | 级别 | 保护 |
|---|---|---|---|
| 个人身份 | 姓名/手机号/身份证 | 高 | 加密工具可用 + 脱敏展示 + 审计拦截明文 |
| 地址 | 小区/楼栋/房号 | 中 | 展示到楼栋，详情按权限 |
| 业务数据 | 工单/提案/咨询 | 中 | 权限控制 + 留痕 |
| 健康信息 | 咨询内容/用药备注 | 高 | 列表不展示全文，详情仅处理人 |
| 日志 | 留痕/异常 | 中 | 只读，7 天 |

## 二、加密存储（utils/crypto.py）

- 生产建议：**AES-256-GCM**（cryptography，`CRYPTO_KEY` 环境变量，base64 32 字节）。
- 本项目演示实现（零依赖）：`utils/crypto.py` —— scrypt 派生密钥 + HMAC 计数流异或 + MAC 校验，
  接口 `encrypt/decrypt` 与 AES-GCM 完全一致可无缝切换；密文 `base64(nonce + ct + mac)`，
  篡改/错密钥均解密失败。
- 密钥：环境变量 `CRYPTO_KEY`；未配置用演示默认值并打日志（生产必须配置）。
- 应用范围：预留（`Crypto` 工具 + 单测覆盖往返/篡改/错钥），敏感列加密迁移按需启用。

## 三、脱敏策略（已落地 + 审计兜底）

- 手机号 `138****1234`：列表/详情/导出全链路脱敏；Agent 回复含完整手机号由合规审计员拦截。
- 姓名 `张*明`：非本人列表脱敏；居民本人可见全名。
- 健康咨询：列表不展示全文（截断 50 字），详情仅处理人（角色校验已做）。
- 导出文件：issues/proposals/notices/knowledge/health/agent-logs 全部脱敏 + 导出留痕。
- **身份证检测**：合规审计员新增 `_IDCARD_RE` 拦截（与手机号同级）。

## 四、密码安全（utils/password.py + 改密端点）

- 策略：≥8 位、必须含字母和数字、禁连续重复字符、禁常见弱密码（123456/password/demo123 等）。
- `POST /api/web/auth/change-password`：旧密码校验（演示居民空密码免旧）+ 强度校验 + PBKDF2 更新 + 留痕。
- 演示账号说明：demo 账号登录不受强度拦截（答辩明确：生产启用强策略，演示账号仅用于演示）。
- 哈希：已有 PBKDF2-SHA256 100k 迭代 + 随机盐（`data/db_core._hash_password`）。

## 五、PIPL 合规闭环

- **隐私政策页**：`/resident/privacy`（收集范围/使用存储/用户权利/联系方式），「我的→隐私政策」入口。
- **数据导出**：`GET /api/web/me/export` —— 导出本人数据 JSON（工单/提案/咨询/对话，手机号脱敏），
  「我的→导出我的数据」入口。
- **账号注销**：`POST /api/web/me/delete` —— 匿名化个人字段 + `is_active=0` + 保留必要日志；
  `auth/me` 校验 `is_active`（注销后 token 失效）；前端二次确认。
- **会话落库**（v31 `agent_sessions`）：Agent 会话 state 持久化，重启不丢、多实例不串线
  （修复评审 P1-C5-01）；取消时清理会话。

## 六、HTTPS 与传输（部署说明）

- 生产：Nginx 反代 + Let's Encrypt + HSTS；演示环境 HTTP 并口头说明。
- 敏感操作均 POST；JWT 已实现；上传已限类型/大小（utils/uploads）。

## 七、合规审计员增强

- 明文手机号 / 完整身份证号 → 拦截；敏感词 → 拦截；导出含敏感 → 拦截（Verifier + Auditor 双防线）。
- 所有敏感操作（看完整手机号/导出/改密/注销）均有留痕（activity_log / agent_logs）。
