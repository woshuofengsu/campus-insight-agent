# 09-UI/UX 设计规范（项目适配版·最终交付）

> 依据《社区服务智能体系统 UI/UX 设计规范》落地，并按本项目（FastAPI + Vue3 三端）实际结构修订。
> 原则：**「温暖、专业、适老、高效」+ 纯视觉层改动，不动任何业务逻辑**。
> 设计令牌已通过 `web/src/style.css` CSS 变量与 `web/src/App.vue` Naive UI themeOverrides 落地，全局生效。

---

## 1. 设计目标与原则

- 居民端：有温度、便捷、像微信一样亲切（底部标签栏 + Agent 聊天优先）。
- 老年端：极简、大字、语音优先、防呆、适老化标杆（字号≥20px、按钮≥60px、行距1.8、语音+文字双通道）。
- 网格员端：高效、专业、企业级工作台、任务驱动（深色导航 + 数字卡片 + AI 工作助手）。

### 2.2 字体 / 间距 / 圆角 / 阴影

- 字体：`--font: "PingFang SC","Microsoft YaHei","Inter","Roboto",sans-serif`；数字英文 Inter/Roboto。
- 字号：居民端 标题18/正文14/辅助12/按钮14；网格员 16/13/12/13；老年端 **24/20/18/22**（WCAG AA，行距 1.8）。
- 间距：XS4/S8/M12/L16/XL24/XXL32（`--sp-*` 语义，组件内直接使用）。
- 圆角：按钮10 / 卡片16 / 弹窗20 / 输入框10 / 标签999 胶囊（`--r-*`）。
- 阴影：一级 `0 1px 4px rgba(0,0,0,.04)`（普通卡片）、二级 `0 4px 12px rgba(0,0,0,.06)`（悬浮/下拉）、三级 `0 8px 24px rgba(0,0,0,.10)`（弹窗）、特殊 `0 4px 16px rgba(239,68,68,.25)`（紧急求助）（`--shadow-*`）。

## 5. 交互与动效

- 页面切换淡入淡出 200ms（`.fade-*`）；卡片 hover 上浮2px + 阴影加深（`.card`）；按钮按压轻微缩放（`.elderly-btn:active`）；主题切换 0.25s 过渡。
- AI 回复打字机效果与骨架屏：属可选项，后续按需在 AgentChat 组件内补充（不阻塞本期交付）。

## 6. 适老化专项（已落地）

字号≥20px / 按钮≥60px / 行距1.8 / 高对比度 / 图标+文字双标注 / 语音优先慢速可重复 / 紧急求助长按3秒+10秒超时取消 / 操作二次确认防误触 / 状态不只靠颜色（附文字与图标）。
