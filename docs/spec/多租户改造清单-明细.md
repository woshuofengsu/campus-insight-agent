## A. 两个必须先知道的事实（决定方案成不成立）

| 事实 | 证据 |
|---|---|
| `DEFAULT_TENANT` 落的是**行政区**、不是社区名 | `config.py:73` → `COMMUNITY_DISTRICT`（默认 `"海淀区"`，`:71`）；实测 `config.DEFAULT_TENANT == '海淀区'` |
| **v41 只回填、从不写入**，租户值已劣化 | `db_core.py:673-686` 只有 `_add_column` + `UPDATE`。实测：`community_issues` 中 `'海淀区'` 224 行、**`''` 128 行**；`notices` **6/6 全空**。写入侧全都不带租户：`db_repair.py:186`、`db_proposal.py:254`、`db_notice.py:235`、`db_governance.py:108/453`、`seed.py:317/405/626`、`live_generator.py:225` |

**推论（最重要）**：只加列 + 回填的"迁移式隔离"必然失效——新数据全是空租户，隔离静默退化成"空租户"。
**写入侧必须与迁移同批改造**，否则就是 v41 的重演。

## B. 租户键 = 社区名（`user_profile.community`）

依据：`config.REGION_BY_COMMUNITY` 以社区名为键（`config.py:80-91`）；JWT 已带 `community`
（`deps.py:49-66`、`auth.py:56-57`）；老 token 有查库兜底（`deps.py:103-124`）；
通知可见范围已按社区算（`db_notice.py:173-182`、`:200-205`）。

**否决行政区当租户键的硬理由**：同区两个社区会互相看见。
**风险**：现存 `'海淀区'` 是区级值，v47 必须显式归一化；`DEFAULT_TENANT` 语义分裂
（`db_core.py:680` 在 fresh DB 上仍按它回填，改它会同时影响测试库与生产库，须一次定稿）。

## E. v47 迁移设计（照现有 `_mN_*` 写法）

```python
def _m47_tenant_isolation(conn):
    """v47：核心表租户隔离。加列 → 归一化 → 按用户社区回填 → 建索引；可重复执行。"""
```
- **加列**：§C 的 10 张表各加 `tenant_id TEXT DEFAULT ''`（照 `db_core.py:618-622` 的 PRAGMA 幂等模式）。
- **归一化**（关键）：把区级值按**显式映射**改成社区名（`'海淀区'` → `'海淀小区'`），
  未命中项 `_log.warning` 计数，**不许静默**。
- **回填**：`UPDATE ... SET tenant_id=(SELECT community FROM user_profile u WHERE u.id=<reporter_id/user_id>)
  WHERE tenant_id='' OR tenant_id IS NULL`；无主的行落 `DEFAULT_TENANT` 并记数。
- **索引**：`CREATE INDEX IF NOT EXISTS idx_<table>_tenant ON <table>(tenant_id)`（照 `_m40` 写法 `db_core.py:652-670`）。
- **注册**：`db_core.py:1099` 后加 `(47, "tenant_isolation", _m47_tenant_isolation)`。
- **可回滚**：新建 `scripts/migrate_tenant_v47.py`（照 `migrate_phone_encryption_v39.py`：`_ensure_db()` + `--rollback`）。
  注意 SQLite `DROP COLUMN` 需 ≥3.35，否则回滚只清值不删列（**待确认**目标版本）。
- **配套写入改造（否则隔离失效）**：§A 列出的 8 处写入路径全部补写 `tenant_id`。

## H. 已知坑

1. **写路径不同步 = 隔离假成功**（最高风险，见 §A）。
2. **测试隔离**：只换 `db_core._DB_PATH`；`conftest.py:45-78` 的 `_isolate_db_path` 会在模块结束复位。
3. **种子数据**：`seed.py:317/405/626`、`live_generator.py:225` 灌种子无租户 → 朝阳居民会看到海淀工单。
4. **前端不能参与隔离决策**（服务端从 JWT 取）；改 `web/src` 后必须 `cd web && npm run build`。
5. **fail-closed**：社区为空必须返回空集。
6. **`DEFAULT_TENANT` 语义分裂**：一次定稿，否则新库回填值仍是区名。
