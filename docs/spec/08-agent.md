# 08-Agent 统一入口模块最终版定义文档（Vue3 主服务实现版）

> 实现载体：FastAPI+Vue3 主服务（api_web.py + web/）。Streamlit 备用端不做。
> Agent 是社区服务智能体的统一入口层，连接居民端、老年端、负责人端。通过自然语言理解、
> 意图识别、智能联想、专业引导，帮助用户高效完成报修、提案、政策问答、通知查询、天气查询、
> 联系社区、数据搜索、导出、统计等任务。Agent 本身不直接处理业务，而是识别意图 → 引导补全
> → 路由执行 → 返回结果。

---

## 一、定位与边界

- 核心定位：统一智能入口层，非独立业务模块。负责：听懂意图 / 专业引导 / 路由到功能模块 / 人性化异常处理 / 高效执行辅助。
- 边界：Agent 不直接处理业务、不替代功能模块、不代替用户做关键决策，只负责「理解 + 引导 + 路由 + 返回」。

| 端 | 用户通过 Agent 能完成 |
|---|---|
| 居民端 | 报修、提案、政策问答、通知查询、天气查询、联系社区 |
| 老年端 | 语音报修、政策问答、联系社区、天气查询、身体不适建议 |
| 负责人端 | 搜索资料、导出数据、查询统计、查看待办、页面跳转 |

## 二、入口与使用条件

| 端 | 前置条件 | 入口 |
|---|---|---|
| 居民端 | 已登录、已绑定社区 | 首页主聊天框，默认展开可收起 |
| 老年端 | 已绑定家属、身份信息完整 | 首页语音对话区，语音优先 |
| 负责人端 | 已登录、已配置角色权限 | 侧边栏 AI 工作助手，默认收起 |

- 频率：不限次数。居民/老年文字≤200字；老年语音≤60秒；负责人导出需确认、敏感数据二次确认。
- 不能用：未登录→跳登录页；老人未绑定家属→提示「请先联系社区绑定家属」；无麦克风→提示开启可用文字；系统维护→提示不可用但紧急求助保持可用；无权限→「您无权执行此操作」。

## 三、意图识别规则

1. 关键词映射 + 联想推断（漏水/灯坏→报修、建议→提案、政策/医保→政策问答、通知/公告→通知查询、天气/温度→天气查询+生活建议、联系社区→电话、怎么用→帮助、你是谁→自我介绍、取消报修→撤回引导、不舒服→身体不适建议）。
2. 负责人专属关键词：导出/报表→导出、统计/多少→统计、待办/超时→待办、查一下/搜索→搜索、打开/跳转→跳转。
3. 紧急语义：哗哗的/快点来/赶紧/马上/很急/爆了/满地都是水 → 自动标记紧急，追问确认。
4. 情绪识别与安抚：还不来/着急/投诉/怎么回事/你们管不管/气死我了 → 先安抚「我理解您的着急，马上为您处理」再引导。
5. 天气生活建议联想：冷→保暖、热→防暑、下雨→带伞、台风→少外出关门窗、暴雨→防积水。
6. 出行场景联想：「我要出门/出去」→「需要帮您查天气吗？」+ 天气快捷按钮。
7. 礼貌用语：「谢谢/感谢/辛苦了」→「不客气，有需要随时找我」。
8. 多意图：识别第一个主要意图先处理，完成后提示「已为您处理XXX，您还需要其他帮助吗？」。
9. 未知意图：「我没太理解您的意思，您可以换个说法」+ 快捷入口按钮。

## 四、追问规则

- 报修：分类（家里/公共区域，默认室内）、紧急程度（紧急/一般，默认一般）。
- 提案：公开/私有（默认私有）。
- 政策：模糊时追问「办理条件还是申请材料？」只追问一轮。
- 追问人性化：按钮代替打字；老年端大字+语音；10秒未回答按默认值；跳过追问直接给完整信息不再追问。

## 五、错别字与病句识别

- 自动纠正（「我加水管漏水」→「我家水管漏水」），纠正后必须用户确认；否认保留原文；纠正失败进入追问或人工。
- 流程：用户输入 → 检测错误 → 自动纠正 → 展示确认 → 继续。

## 六、语音输入规则（老年端）

单次≤60秒超时自动结束；转写失败提示重试保留已识别内容；转写成功先展示文字老人确认后执行；确认超时10秒自动取消保留草稿；播报失败重试3次仍失败显示文字。

## 七、回复规则

- 居民端：文字简洁、状态颜色统一、可点快捷按钮、带下一步引导。
- 老年端：大字版+语音播报、口语化不超过两行、可「再听一次」。
- 负责人端：信息密度高、导出提供下载入口、统计数字突出、待办可点击跳转、提醒「建议优先处理超时工单」。

## 八、权限规则

| 端 | 能 | 不能 |
|---|---|---|
| 居民 | 本人+绑定家属事务、看自己历史对话（5条可删）、自己报修/提案/通知/天气 | 查看他人数据、代替审核/修改状态/导出/看完整手机号/代替转人工/代替反馈满意度 |
| 老年 | 本人事务、历史对话（5条大字不可删）、报修进度、大字天气 | 关闭提醒、代替确认重要操作、查看他人数据、修改状态、删除历史、看完整手机号、代替触发紧急求助 |
| 负责人 | 权限内搜索、导出（确认）、统计、待办、跳转 | 代替审批/回复、发布紧急通知、关闭工单、看完整手机号（需二次确认）、自动下架、代替确认检查任务、看居民健康咨询（仅处理人） |

## 九、三端流程（核心闭环）

- 居民：报修（追问分类/紧急 → 草稿确认 → 提交返工单号）；提案（追问公开/私有 → 草稿确认 → 提交返编号）；政策问答（答案 + 有帮助/无帮助 → 无帮助转人工）；通知列表；天气+建议；联系社区（电话+一键拨打）；帮助/自我介绍；撤回引导（待审核可撤回）。
- 老年：语音报修（转写确认 → 默认室内/一般 → 确认提交 → 播报）；政策问答（大字+播报）；联系社区（确认拨号，10秒超时取消）；天气大字+播报；身体不适（提示联系社区/家属 + 紧急求助按钮）；使用帮助语音播报。
- 负责人：待办统计（超时红标 + 跳转）；导出（确认 → 脱敏文件下载）；搜索（按地址/姓名返回列表可跳转）；跳转页面；统计数字；模糊指令提示补全。

## 十、验收标准

- 意图识别准确率 ≥95%；错别字纠正准确率 ≥90%；紧急语义识别 100%；情绪安抚触发 100%；响应时间 ≤3秒；导出脱敏（不含完整手机号/附件/正文全文）；留痕字段完整。
- 智能联想：「还是老问题」查上次记录提示确认；「那个灯」联想报修-灯追问家里还是楼道；「我好冷」返回天气+保暖；「我要出门」提示查天气。
- 用户不按流程：跳过追问直接生成草稿；追问答非所问再问一次或默认值；10秒默认值；中途「算了」提示已取消不生成草稿；中途改话题暂停当前处理新话题再回来；情绪激动先安抚。
- 越权场景全部拒绝并留痕。

## 十一、停机点（必须停下来问人）

- A类（自动触发必须留痕可复核）：意图识别、纠错（先确认再继续）、联想（提示确认）、知识库匹配、天气/通知/待办/搜索返回、情绪安抚、礼貌回复、帮助、自我介绍。
- B类（用户确认）：报修/提案草稿提交、转人工、联系社区拨号、纠正后确认、追问默认值确认（超时按默认值需提示）。
- B类（负责人批准）：导出数据（确认范围内容）、查看完整手机号（点击+二次确认）、敏感操作二次确认。
- 特殊停机点：情绪激动先安抚；报修缺地址自动带出不打断；老人未绑定家属停下来提示；老人未配紧急联系人允许非紧急功能但求助提示配置；紧急通知发布/工单关闭/内容下架/代替审批 Agent 均不能执行，必须负责人手动。

## 十二、异常处理与留痕

- 意图识别失败/模糊/未知 → 提示重新描述 + 快捷入口；多意图先处理第一个。
- 语音异常：转写失败/为空→重试；超长60秒自动结束；确认超时10秒取消保留草稿；播报失败3次显示文字。
- 业务异常：知识库失败→转人工；工单/提案生成失败→保留草稿提示重试；导出失败记日志；导出过大→分批；天气失败→缓存+标注时间（超15分钟提示延迟）。
- 权限异常：无权限→拒绝+日志；敏感未确认→拦截；越权→拒绝+日志。
- 系统异常：服务不可用提示重试快捷入口可用；网络中断重试；防重复提交；并发冲突提示刷新。

- 留痕字段：操作人/操作时间/模块来源=Agent/用户输入/纠正后内容/识别意图/路由结果/执行状态/异常信息/关联业务编号。
- 查询权限：负责人可查完整留痕（按模块/时间/状态筛选）+ 可导出（脱敏，导出本身留痕）；居民/老人不可见留痕，仅看自己历史对话。
- 保存时间：业务留痕 7 天；异常日志单独 7 天。
