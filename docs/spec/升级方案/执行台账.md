## 0. 执行纪律（本项目既有硬约束，升级期间同样有效）

1. 每批改完必须：`python -m ruff check .` 为 0；`python -m pytest tests/ -q` 全绿（跑测试前**停掉 :8000 服务**）。
2. 改 `web/src` → 必须 `cd web && npm run build`，并重跑 `ui_audit` / `mobile_audit`（两者**需要服务在跑**）。
3. **禁止运行时 ALTER**：加表/加列只走 `data/db_core.py` 的迁移注册表（`_mN_*` + 幂等）。
4. 口径门禁：`check_claims.py` 必须全绿；对外材料的数字只能由 `scripts/sync_test_count.py` 与实测值驱动。
5. 安全类校验 fail-closed；`except` 禁止静默吞异常（有门禁测试）。
6. 每张卡要**留回退点**：能一句话说清"怎么退回上一个可用状态"（git 提交 + 数据备份）。
