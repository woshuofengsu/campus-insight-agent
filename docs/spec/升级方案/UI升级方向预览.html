1

一个主要动作，另一个明确出口

“我要报修”有最强视觉权重，“查看进度”随手可达。不用六张同样鲜艳的卡片让用户重新判断。

2

状态旁边写下一步

只显示“待补充”还不够。告诉居民缺少什么，并给出直接入口。完成、失败与结果未知分别表达。

3

AI 是服务入口，不占满首页

开始会话后才进入完整对话区域。技术链路保留在授权详情中，不要求普通居民理解 Agent 名称。

4

统一颜色的职责

蓝色承担主操作与选中，绿色表示已完成，琥珀表示等待或补充，红色留给真正危险。

03 / ACCESSIBLE SERVICE

把简单留给老人

减少多行导航与重复入口。首页负责找服务，内页负责完成一件事；大字与大热区配合明确文字。

少选择 · 易返回 · 能恢复

1

不再每页列出八个导航

首页承担主要入口，内页提供大返回和回首页。按钮数量要由实际任务观察决定。

2

大字之外，还要降低选择负担

一行简短动作文字，一个清楚结果。主操作区不需要说明技术架构或展示统计分数。

3

紧急动作单独处理

视觉改版保留原有长按、确认和取消机制；本稿不模拟真实求助，不改变响应承诺。

4

语音始终有替代方式

语音失败时能看文字、点预置短语、联系帮助。不因设备不支持语音就失去入口。

实施前的真实验证

候选目标：正文 20～22px，核心热区 64～72px。仍需检查文字放大、焦点、对比度与实际老人操作，静态概念图不能证明达标。

04 / HONEST STATES

漂亮，也必须说真话

把加载、空数据、失败、结果未知和成功分开。正确状态是 UI 与技术升级的共同契约。
