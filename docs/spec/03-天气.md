# 第三部分：天气功能（最终完善版·含全部压测修正）

## 一、要完成什么

定位：天气功能为全体用户提供社区天气信息，并在极端天气前触发分级提醒，联动负责人检查和老年端主动播报。

使用对象：所有人（居民、家属、负责人、老年人）。

提供内容：实时天气、未来 3 天预报、极端天气预警、穿衣/出行建议（系统根据当天天气数据自动生成基础建议，每天生成一次，不使用 AI 自由发挥）。

使用方式：
- 居民端：主动查询，侧边栏导航进入专门天气页面。
- 老年端：不设独立专门天气页面，但在老年端极简首页提供大字版简化天气展示，复用天气数据，只显示温度、天气现象、预警标签和一句建议，不显示完整预报。
- 负责人端：打开后台时可见所有社区天气概况和极端天气检查任务。

联动机制：极端天气前提醒老人减少外出；提醒负责人检查公共设施，但只提醒，不自动生成报修工单，由负责人手动决定后续动作。

定位方式：默认定位到用户所属社区，按大致天气展示，不要求精确经纬度，不可手动切换。

数据来源：和风天气 API。更新频率：实时天气每 10 分钟刷新；预报每天更新 2 次（早 8 点、晚 8 点）。

数据源故障：采用缓存降级，保留上次成功数据，提示"数据更新于XX时间，当前不可用"，并记录异常日志；同时暂停新的预警触发提醒，已触发的滚动提醒保留并标注数据更新时间。

极端天气标准：暴雨、台风、高温、寒潮、大风、雷电、冰雹、大雾。

## 二、谁、什么时候能用

- 居民端入口：侧边栏导航进入专门天气页面，需登录后查看。
- 老年端入口：极简首页点击"天气"按钮，展示大字版简化天气预报；极端天气预警主动弹窗+语音播报，无需老人打开页面。
- 负责人端入口：登录后台查看所有社区天气概况和检查任务。
- 滚动提醒：居民端网页顶部和负责人后台网页顶部均有极端天气滚动提醒。
- 极端天气提醒触发：系统检测到极端天气预警后，若预警生效时间在未来 12 小时内，则立即触发提醒。
- 老人减少外出提醒：极端天气持续期间，每天上午 8 点提醒一次，语音播报一次，音量可调大。
- 负责人检查任务：负责人收到"极端天气检查任务"提示后，需在 3 小时内确认已检查；超时标记"超时未确认"，允许补填，保留超时标记。

## 三、开工前必须拿到什么

前置配置：
- 用户登录并绑定所属社区，系统按社区展示大致天气，不要求精确经纬度。
- 已接入和风天气 API，配置密钥、接口地址、调用频率限制。
- 极端天气判定规则细化到预警等级，不同等级对应不同提醒动作。
- 提醒模板按天气类型区分：暴雨、台风、高温、寒潮、大风、雷电、冰雹、大雾分别准备专属文案。
- 负责人检查任务按极端天气类型匹配具体检查清单。
- 天气 API 异常时采用缓存降级。
- 滚动提醒在极端天气生效期间持续显示，居民可临时关闭，但每次登录或每 6 小时再次出现。
- 老年端语音提醒需配置语音文案，每天提醒一次，播报一次，音量可调大。
- 负责人账号及权限配置：确定哪些负责人接收检查任务，同时配置更高级负责人作为兜底。
- 更新频率配置：实时天气每 10 分钟刷新；预报每天早晚 8 点更新。
- 异常日志记录配置：API 故障、提醒发送失败等单独记录，保存 7 天。

## 四、按什么规矩办

1. 极端天气类型：暴雨、台风、高温、寒潮、大风、雷电、冰雹、大雾。
2. 预警等级触发：黄色及以上预警即触发提醒；红色预警加强提醒（老年端语音重复播报两次+滚动置顶）。
3. 提醒触发时机：系统检测到预警后，若生效时间在未来 12 小时内，立即触发；超过 12 小时不触发。
4. 老人减少外出提醒：极端天气持续期间每天上午 8 点提醒一次，语音播报一次，音量按老人设置，不强制最大音量；红色预警重复播报两次。
5. 负责人检查任务：收到提示后 3 小时内确认已检查，不同天气类型匹配具体检查清单；超时未确认标记"超时未确认"，允许补填，保留超时标记。
   - 超时升级（压测修正）：超时后系统立即通知所有在线负责人，并持续提醒，直到有人确认；若仍无人确认，保持超时标记并升级至更高级负责人。
   - 更高级负责人未配置（压测修正）：系统持续提醒当前所有在线负责人，直到有人确认；同时记录"无法升级"日志，并保持最高优先级告警。
   - 升级通知连续失败（压测修正）：若升级通知发送失败，系统重试一次；仍失败则标记"升级通知失败"。若更高级负责人通知也失败，系统保留最高优先级告警，显示"紧急天气检查任务等待人工介入"，并通知系统管理员。
6. 滚动提醒：居民端和负责人端顶部滚动显示，极端天气生效期间持续存在；居民可临时关闭，但每次登录或每 6 小时再次出现；负责人端同样可临时关闭。
7. 数据更新频率：实时天气每 10 分钟刷新，预报每天早晚 8 点更新。
8. 缓存降级：API 异常时保留上次成功数据，提示"数据更新于XX时间，当前不可用"；暂停新的预警触发提醒，已触发的滚动提醒保留并标注数据更新时间。
   - 数据更新时间戳异常监测（压测修正）：系统后台持续监测数据更新时间，若超过 15 分钟未更新，页面提示"天气数据可能延迟"，记录异常日志；若超过 30 分钟未更新，按 API 故障处理，启动缓存降级。
9. 穿衣/出行建议：系统根据当天天气数据自动生成基础建议，每天生成一次，不使用 AI 自由发挥。
10. 定位规则：按用户绑定社区展示大致天气，不要求精确经纬度，不可手动切换。
11. 同一时段多个极端天气预警（压测修正）：按预警等级最高者优先展示；老年端语音播报最多播报两个最高等级类型，按预警等级从高到低播报，若等级相同按发布时间先后播报；居民端和负责人端滚动提醒可同时展示多个预警，按等级排序。

## 五、分几步完成

1. 用户登录，系统识别用户所属社区。
2. 用户打开天气页面，系统调用和风天气 API 获取该社区实时天气和未来 3 天预报。
3. 页面展示：温度、天气现象、风力、湿度、空气质量、紫外线、预报、穿衣/出行建议（每天生成一次）。
4. 系统后台每 10 分钟检测一次极端天气预警。
5. 检测到极端天气预警，且生效时间在未来 12 小时内，立即触发提醒。
6. 提醒分发：居民端顶部滚动提醒；负责人端顶部滚动提醒 + 生成"极端天气检查任务"；老年端主动弹窗+语音播报。
7. 负责人收到检查任务后，按对应天气类型的检查清单执行检查，并填写检查结果和备注。
8. 若负责人在 3 小时内未确认，系统标记"超时未确认"，并立即通知所有在线负责人，持续提醒直到有人确认；若无人确认，升级至更高级负责人。
9. 极端天气持续期间，系统每天向老年端发送一次减少外出提醒（主动弹窗+语音）。
10. 极端天气预警解除后，滚动提醒消失，检查任务关闭，老年端已弹窗自动消失。

## 六、工具与权限边界

### 居民
- 能：查看自己所属社区天气页面、未来 3 天预报、穿衣/出行建议；接收顶部滚动提醒；临时关闭滚动提醒（每次登录或每 6 小时再次出现）。
- 不能：查看其他社区天气、修改天气数据、查看负责人检查任务、关闭老年端提醒、调整预警规则。

### 负责人
- 能：查看所有社区天气概况；查看顶部滚动提醒；接收并处理"极端天气检查任务"，填写检查结果和备注；查看检查任务历史记录；临时关闭滚动提醒（不留痕）。
- 不能：修改天气数据、代替其他负责人确认检查、删除检查任务、调整预警等级或阈值。

### 老年用户
- 能：接收极端天气主动弹窗和语音播报提醒；调节音量；红色预警时系统重复播报两次，但不强制最大音量，按老人设置音量播报。
- 不能：查看专门天气页面、查看预报详情、关闭或屏蔽提醒、修改任何天气相关设置。
- 老年端大字版天气展示：可在极简首页查看大字版简化天气，显示字段：当前温度、天气现象、最高/最低温、极端天气预警标签、一句话建议；可点击"播放天气"语音播报。

### AI agent
- 能：获取天气数据、展示天气信息、检测极端天气预警、触发提醒、生成检查任务、生成穿衣/出行建议。
- 不能：修改天气数据、代替负责人确认检查、删除检查任务、查看居民个人隐私信息、调整预警等级或阈值。

## 七、标准输出

### 居民天气页面
当前温度（大字号）、天气现象、最高温/最低温、风力等级、湿度、空气质量指数、紫外线指数、未来 3 天预报（每天天气、最高/最低温）、穿衣建议、出行建议、极端天气预警标签（如有：黄色/橙色/红色）、数据更新时间。

### 负责人后台极端天气展示
1. 顶部滚动提醒：极端天气类型、预警等级、生效时间；可临时关闭，每次登录或每 6 小时再次出现。
2. 极端天气检查任务卡片：天气类型、预警等级、检查清单（按天气类型匹配的具体检查项，可逐项勾选"已检查/正常/异常"，每项可填写备注）、任务状态（待检查/已确认/超时未确认）、剩余确认时间（3 小时倒计时，超过 1 小时绿色、少于 1 小时红色、超时灰色）、操作按钮（填写检查结果和备注、确认已检查）、超时未确认后允许补填并保留标记。
3. 历史检查任务记录：时间、天气类型、预警等级、检查人、检查结果、备注、是否超时；支持按时间、天气类型、状态筛选。
4. 所有社区天气概况：社区名称、当前天气、温度、预警标签（如有）；支持搜索或筛选。

### 老年端极端天气提醒
- 弹窗：天气类型、预警等级、简短提醒语、生效时间；大字体、高对比度、天气图标；预警等级用颜色区分；增加"我知道了"按钮，点击关闭当次弹窗，不影响语音播报。
- 语音播报：口语化，一句话说清天气和行动建议；默认慢速；黄色/橙色按老人设置音量，红色重复播报两次，不强制最大音量。
- 提醒时间：极端天气预警触发当天立即播报一次，之后每天上午 8 点提醒一次，持续到极端天气结束。
- 不可关闭或屏蔽，只能调节音量。

### 老年端大字版天气页面
- 顶部显示"XX社区天气"；当前温度（超大字号，红色高温显示红色，低温显示蓝色，一般天气黑色）；天气现象配大图标（至少 60px）；最高温/最低温；极端天气预警标签（大号彩色标签，配合图标）；一句话穿衣/出行建议（口语化，不超过两行）；"播放天气"按钮（大按钮，完整播报）；数据更新时间（只显示"更新于XX:XX"）；返回首页按钮（固定在底部，大而醒目）。

## 八、验收标准

1. 天气数据获取成功：页面字段齐全。
2. 数据更新频率达标：实时每 10 分钟刷新；预报每天早晚 8 点更新。
3. 社区定位正确：不同社区用户展示各自所属社区大致天气。
4. 穿衣/出行建议生成正确：建议与当天天气匹配，一天内不变化，跨天重新生成。
5. 极端天气预警检测准确：8 类极端天气，黄色及以上触发，红色加强。
6. 预警触发时机正确：生效时间在未来 11 小时触发，未来 13 小时不触发。
7. 居民端滚动提醒：极端天气期间打开网页顶部显示；可临时关闭，重新登录或每 6 小时再次出现。
8. 负责人端滚动提醒和检查任务：顶部滚动提醒 + 自动生成检查任务卡片。
9. 检查任务处理：填写检查结果和备注并确认，状态"已确认"；3 小时未确认标记"超时未确认"，允许补填保留标记。
10. 检查清单逐项勾选：每项状态可独立保存，最终检查结果能汇总展示。
11. 不同天气类型匹配不同文案和清单：抽查暴雨和台风，不出现通用模板。
12. 老年端提醒：主动弹窗+语音，每天上午 8 点提醒；红色重复两次，黄色/橙色一次；音量按老人设置；可点"我知道了"关闭弹窗，语音照常；无法关闭或屏蔽。
13. 老年端大字版天气展示：字段齐全，温度颜色变化，播放天气按钮可语音播报，数据每 10 分钟同步。
14. 缓存降级：API 故障时保留上次数据，提示"数据更新于XX时间，当前不可用"，记录异常日志；暂停新的预警触发。
15. 预警解除后处理：滚动提醒消失，检查任务关闭，老年端已弹窗自动消失。
16. 权限验证：居民仅看本社区天气；负责人可查看所有社区概况；老年用户仅收提醒和大字版简化展示。
17. 历史检查任务记录：字段完整，支持筛选。
18. 异常日志：单独记录，保存 7 天。
19. 同一时段多个预警：按等级排序展示；老年端最多播报两个最高等级。
20. 检查任务超时升级（压测修正）：超时后立即通知所有在线负责人并持续提醒；无人确认则升级更高级负责人。
21. 数据更新时间戳异常（压测修正）：超 15 分钟提示延迟，超 30 分钟按故障缓存降级。
22. 更高级负责人未配置（压测修正）：持续提醒在线负责人，记录"无法升级"日志，保持最高优先级告警。
23. 升级通知连续失败（压测修正）：重试后仍失败，保留最高优先级告警，显示"紧急天气检查任务等待人工介入"，并通知系统管理员。

## 九、停机点

### A 类：系统自动触发，必须留痕，负责人可事后复核
- 天气数据获取与更新。
- 极端天气预警检测与提醒分发（居民滚动、老年弹窗语音、负责人检查任务生成）。
- 红色预警老年端播报（按老人设置音量，重复两次，系统自动执行）。
- 预警解除后自动关闭检查任务，老年端已弹窗自动消失。
- 缓存降级：保留上次数据，提示不可用，暂停新预警触发。
- 穿衣/出行建议自动生成。
- 数据更新时间戳异常监测与自动降级（压测修正）。
- 检查任务超时自动升级通知（压测修正）。
- 更高级负责人未配置时的持续提醒与日志记录（压测修正）。
- 升级通知失败时的最高优先级告警保留与系统管理员通知（压测修正）。

### B 类：必须负责人明确批准后才能执行，系统不能自动触发
- 红色预警可能影响社区公共安全时，系统只生成检查任务并提醒，不自动执行社区应急措施（如关闭公共设施、通知疏散、启动应急预案），由负责人决定。
- 天气 API 异常时系统自动暂停新预警触发并通知负责人；负责人可决定是否手动发布预警提醒。
- 负责人检查任务超时未确认：系统不自动升级、不代填，只标记"超时未确认"，由负责人后续补填。

### 边界确认
- 红色预警播报由系统自动执行，不需要负责人批准；音量按老人设置，重复两次，不强制最大音量。
- 天气 API 异常时暂停新预警触发，已触发的滚动提醒保留并标注数据更新时间。
- 预警解除后，老年端已弹窗自动消失。
- 检查任务超时后系统自动通知所有在线负责人，但不代替任何人确认，需有人手动确认。
- 更高级负责人未配置或升级通知失败时，系统不停止告警，持续保留最高优先级，直到人工介入。

## 十、异常与留痕

### 异常处理
1. 天气 API 故障或超时：保留上次成功数据，提示"数据更新于XX时间，当前不可用"；暂停新预警触发；记录异常日志。
2. 提醒发送失败：自动重试 3 次，每次间隔 5 分钟；3 次仍失败标记"提醒发送失败"，通知负责人人工介入。
3. 预警检测任务异常：系统先自动重新触发一次；恢复成功不打扰负责人；仍失败通知负责人手动执行一次检测。
4. 用户未登录访问天气页面：跳转登录页，不展示数据。
5. 用户未绑定社区：提示"请先绑定所属社区"，不展示数据。
6. 和风天气 API 返回数据格式异常：按 API 故障处理，显示缓存数据并提示不可用。
7. 同一时段多个极端天气预警：按等级排序，老年端最多播报两个最高等级。
8. 数据更新时间戳异常（压测修正）：超 15 分钟提示延迟；超 30 分钟按故障缓存降级。
9. 检查任务超时升级通知失败（压测修正）：重试一次仍失败标记"升级通知失败"；若更高级负责人通知也失败，保留最高优先级告警，显示"紧急天气检查任务等待人工介入"，通知系统管理员。
10. 更高级负责人未配置（压测修正）：持续提醒在线负责人，记录"无法升级"日志，保持最高优先级告警。

### 留痕规则
- 范围：只记录关键操作——预警检测、提醒分发、负责人处理检查任务、缓存降级、数据更新时间戳异常、升级通知失败等；居民查看天气仅记录系统访问日志，不进入业务留痕。
- 字段：操作人（或系统）、操作时间、操作类型、操作前值、操作后值、关联社区、天气类型、预警等级等；天气查看类操作只记录访问时间、社区、天气类型。
- 查询权限：负责人可查看天气相关完整留痕；居民不可见；老年用户不提供留痕查询。
- 导出：负责人可导出天气检查任务记录和异常日志，不含居民访问日志。
- 系统异常日志：单独记录，保存 7 天，不混入业务留痕。
