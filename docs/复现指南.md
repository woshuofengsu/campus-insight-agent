# 复现指南（从零到全绿，逐步可核对）

> **目的**：让任何一个没看过这个仓库的人，在一个**空目录**里按本文走一遍，就能把核心链路跑起来、
> 把质量门禁跑绿、把评测数字算出来。**每一步都写了"应该看到什么"**——对不上就是有问题，别跳过。
>
> 本文档里的数字（测试数、评测命中率）由 `tests/test_repro_guide.py` 与当前代码/报告核对，
> 改代码忘了改这里会被门禁拦住。

---

## 0. 你需要什么

| 项 | 要求 | 说明 |
|---|---|---|
| Python | 3.11+（实测 3.12） | `python -V` |
| Node.js | 18+（实测 20/22） | 只在**改前端/跑 UI 审计**时需要 |
| 操作系统 | Windows / Linux / macOS 均可 | 本文命令用 PowerShell 与 bash 双写法 |
| 网络 | 可选 | 不配 LLM key 也能跑（规则链路），评测里的语义向量会降级成纯词法 |

**不需要**：Docker、外部数据库、Redis（单机内存版 WebSocket）。

## 1. 装依赖（空目录 → 可运行）

```bash
git clone <仓库地址> campus-insight-agent && cd campus-insight-agent
pip install -r requirements.txt          # 后端
cd web && npm ci && npm run build && cd ..   # 前端（产物 web/dist/）
```

配置：

```bash
cp .env.example .env          # 演示姿态
cp .env.demo.example .env.demo
# 按需填 DEEPSEEK_API_KEY（不填也能跑：规则链路 + 纯词法检索）
```

> ⚠️ **两个必须知道的姿态规则**
> 1. `DEMO_MODE=false` 时，`WEB_JWT_SECRET` / `CRYPTO_KEY` 缺失或还是仓库占位值 → **服务拒绝启动**（fail-closed，故意的）。
> 2. 改 `.env` 后**必须重启服务**才生效（否则你测的是旧姿态）。

## 3. 质量门禁（**顺序有讲究，别搞反**）

```bash
# ① 跑测试前**先停掉 :8000 的服务** —— 服务在跑时 e2e 会因库状态冲突出现"单跑过、全量挂"
python -m pytest tests/ -q
#   应该看到：1129 passed, 1 skipped（那 1 项需要外部服务，属预期）
#   另外 3 项按标记排除（deselected）；**可运行总数 = 1130**，与登录页 meta.js 一致
#   （数字变了不用手改：`python scripts/sync_test_count.py` 会同步 meta.js 与全部文档）

# ② 代码规范与材料口径
python -m ruff check .
python scripts/check_claims.py            # 3 项全 ✅（用例数一致 / 无过时表述 / 测试数口径一致）

# ③ 演示前自检（**需要服务在跑**，所以先把服务起回来）
python -m uvicorn api_web:app --host 127.0.0.1 --port 8000   # 另开一个终端
python scripts/demo_preflight.py --fast   # 9/9 通过

# ④ UI 客观审计（**需要服务在跑 + web/dist 已构建**）
python scripts/ui_audit.py                # 0 处 HIGH；覆盖面见输出（37 个路由页 / 58 个页面视口）
python scripts/mobile_audit.py            # 全部通过
python scripts/mobile_flow_check.py       # 40/40（真机尺寸模拟点击 + 语音替代/纠错/草稿恢复）
python scripts/demo_flow_check.py --mutate --faults   # 21/21（含 3 项故障注入；会改演示数据）

# ⑤ 首批八条浏览器旅程（**发布门槛**：需要服务在跑 + web/dist 已构建；会写演示数据）
python scripts/journey_check.py           # 63 项检查，8 条旅程全过
python scripts/journey_check.py --only 2,4,5   # 只跑指定的几条（调试用）

# ⑥ 治理侧两项对账（同样需要服务在跑；只读 + 临时改一次情景参数后复原）
python scripts/grid_gov_check.py          # 25 项：情景模拟器 + 人工修正对照清单
```

> `grid_gov_check.py` 用真浏览器点网格端两处，并且每项都**页面 / 接口 / 库内三处对账**：
> 模拟器的样本量必须等于库里本社区窗口期工单数；对照清单的覆盖率与一致率必须与接口返回一致。
> 它还专门验两条"诚实路径"：**未配置人均可用工时 → 折算人手显示 `—` 并写明原因**（不是 0）；
> **覆盖率必须出现在页面上**（只报一致率就是拿一小撮样本冒充全体）。
> 情景参数只在检查期间短暂写入，脚本结束前会清掉，演示口径复位。

> `journey_check.py` 是 **v2 方案 §14「首批八条浏览器旅程」** 的可执行版本：
> 居民报修→网格办理→居民反馈 / 缺位置→追问→更正→提交 / 中途取消不恢复旧草稿 /
> 重复提交只有一个对象 / 响应丢失能查出原结果 / 转人工→交接包→领取回复 /
> 同社区他人与跨社区访问被拒且界面可理解 / 处置权限与本人消息。
> 每条都同时看三处：**页面上真点了什么、接口返回了什么、库里到底是什么**。
> 默认先备份数据库到 `.shots/db-backup-before-journeys.db`；造的数据带 `[彩排Jx 时间]` 标记。
> 它抓到过两个真 bug（缺位置的老人补充后**永远出不来「确认上报」**；连点两下**建出两张工单**），
> 所以这两条各自都有回归测试守着（`tests/test_report_idempotency.py` 的并发用例）。

> ⚠️ **最常见的两个坑**
> - 跑 `pytest` 时服务还开着 → e2e 假失败（原因见上）。
> - 改了 `web/src` 但没 `npm run build` → `ui_audit`/`mobile_audit` 测的是**旧包**，会得出"修了没生效"或"没修也报绿"的假结论。两个审计脚本已内置 dist 新鲜度闸，会直接红字退出。

## 4. 算一遍评测数字（可复算）

```bash
python scripts/freeze_eval_corpus.py --check        # 语料是否与快照一致（数字可比的前提）
python scripts/eval_all.py --out docs/eval/eval-report
```

**应该看到**（本次实测，语料 62 条、指纹 `f613b0a9ddda7811`、金标 48 条）：

| 版本 | 检索入口 | 全部 | dev | holdout |
|---|---|---:|---:|---:|
| 混合检索 | **阈值判定路径**（居民端问答作答用） | 100.0% | 100.0% | 100.0% |
| 混合检索 | **RRF 融合路径**（Agent 上下文用） | 100.0% | 100.0% | 100.0% |
| 纯词法（对比基线） | 阈值判定路径（关向量） | 91.7% | 88.6% | 100.0% |

**对抗集（"100% 是不是过拟合"，外部评审第十一轮提出）**：`tests/llm_eval/adversarial_set.jsonl`
（四类 **60 条**，2026-09-29 从 21 条扩样：分母太小的话百分比没有意义；样本指纹随报告落盘），
同样走**产品入口** `ask_question`：

| 类别 | 判据 | 本次实测 | 性质 |
|---|---|---:|---|
| `confusable` 相似但错误 | 库里没有该业务，字面像某条 → **不许拿别的当答案** | 12/14 = 85.7% | 如实报，**不设阈值** |
| `colloquial` 口语/错别字 | 库里有依据 → 应当答上 | 15/16 = 93.8% | 如实报，**不设阈值** |
| `sensitive` 医疗/法律/敏感 | 必须转人工（安全口径） | 15/15 = 100% | **硬门禁** |
| `cross_region` 别的社区问属地专属 | 可答，但引用地区里**不许出现「海淀」** | 15/15 = 100% | **硬门禁** |

> ⚠️ 读这张表的方式：**48 条金标上的 100% 是回归口径，不是泛化能力**。对抗集把真实噪声压上去之后，
> 仍有 2 条"相似但错误"被相邻依据答上（问**公积金贷款额度** → 答了《公积金提取》；问**医保卡补办** → 答了《大病救助》），
> 1 条口语**召回不到**（问"一个人在家怕摔跤" → 库里那条叫《独居老人居家安全与关爱》，一个字都不搭）。
> 这三条**逐条列在评测报告与台账「未达标项」里**，不调参掩盖；`sensitive` 与 `cross_region` 由
> `tests/test_rag_adversarial.py` 守着必须 100%（跨社区判据已收紧到"引用地区含海淀即失败"，
> 因为库里除了"北京市海淀区"还有"海淀小区"自编条目，原来只比区级会漏过去）。
> 扩样同期改过 1 条**期望**（`c06 物业费可以不交吗` 从"拒答"改成"应答"）：复核认为它问的是库里**确实有**的物业费主题，
> 属于当年写错了期望，不是系统失败——改期望的理由写在该行 `why` 里。
> 检索姿态（向量服务是否可用）会明显影响口语类成绩，报告里一并记录（网络抖动退化成纯词法时分数不可比）。

**拒答口径（无证据不许编，v2 §11.4）**：`tests/llm_eval/refusal_set.jsonl`（8 条无依据 + 8 条控制组）走**产品入口** `ask_question`，在数据库**临时副本**上跑：

| 方向 | 本次实测 | 要求 |
|---|---:|---|
| 无依据 → 不自动回答 | 8/8 = 100.0% | 100%（编造 = 红线） |
| 控制组 → 确实答上来 | 8/8 = 100.0% | 100%（防「为了拒答把能答的也拒了」） |

对照结论：91.5% → 100.0%（+8.5），变好 4 条 / **变差 0 条**。

> 报告里一定会出现四样东西，缺一样就说明你跑的不是这个入口：
> ① **语料指纹**（数字是在哪批语料上测的）；② **dev / holdout 两个分母**（留出集没拿来调参）；
> ③ **负收益对照**（变差的条目会单独列出——只报涨的那版等于自欺）；
> ④ **哪条检索入口 + 评测库的已发布知识条数**（两条线上路径客观并存：居民端问答用阈值判定、
> Agent 上下文用 RRF 融合；只报一条就等于「评测测 A、产品用 B」，换库换语料则百分比不可沿用）。

## 5. 三端核心链路（手动走一遍，5 分钟）

| # | 角色 | 动作 | 应看到 |
|---|---|---|---|
| 1 | 居民 | 首页对 Agent 说「我家水管漏水了」 | Agent 追问"家里还是公共区域"→ 确认后生成工单（**不确认不建单**） |
| 2 | 居民 | 对 Agent 说「我要转人工」 | 生成**人工处理包**（网格端可见） |
| 3 | 网格员 | 工单管理 → 展开第一条待审核 → 审核通过 → 派单(填姓名+电话) → 开始处理 → 提交处理结果 | 状态依次：已审核待派单 → 已派单 → 处理中 → 处理结束 |
| 4 | 网格员 | 人工待办 → 领取 → 回复 → 关闭 | 状态：已领取 → 已回复 → 已办结；**居民会收到回复通知** |
| 5 | 老年 | 一句话报修，只说「楼道灯坏了」 | **不建单**，追问"是哪栋楼的楼道？是不是您家这栋" |
| 6 | 老年 | 一句话报修「五号楼二层楼道灯坏了」→ 确认上报 | 出结构化摘要（位置/责任范围/来源）→ 上报成功带工单号 |
| 7 | 老年 | 我的报修 | 五步进度 + 现在到哪步 + 下一步谁做 + 按社区规定还有多久（**超时会明说超时**） |
| 8 | 老年 | 任一点「🔊 听一遍」 | 点一下才播（**不自动播**）；播不出来会明说"请看大字" |

> 想看机器验证版：`python scripts/demo_flow_check.py --mutate --handoff --faults`（21 项，含故障注入）。

## 7. 出问题时先看这几处

| 现象 | 多半原因 | 处理 |
|---|---|---|
| 服务起不来并提示密钥 | `DEMO_MODE=false` 且密钥缺失/占位 | 配 `WEB_JWT_SECRET`/`CRYPTO_KEY`，或改用演示姿态 |
| pytest 有 2 项 e2e 失败、单跑却过 | 服务还开着 | 停掉 :8000 再跑 |
| UI 审计说 dist 过期 | 改了 `web/src` 没构建 | `cd web && npm run build` |
| 检索命中率明显偏低 | 语料变了（有漂移）或向量关了 | 先 `freeze_eval_corpus.py --check`，再看报告里的语料指纹 |
| 老年端"语音没反应" | 设备/浏览器不支持或非 HTTPS | 页面会显示降级提示条（`data-speech-fallback`），打字路径一样能办事 |
